# Day 5 - Linux Learning

## Topics Covered

1. find

3. which
4. whereis

7. tee

# 1. which

Shows the executable path of a command.

Examples:

```bash
which ls
which git
which bash
```

Example output:

```text
/usr/bin/ls
/usr/bin/git
/usr/bin/bash
```

# 2. whereis

Shows the executable, source files, and manual pages (if available).

Examples:

```bash
whereis ls
whereis git
whereis bash
```

Example output:

```text
ls: /usr/bin/ls /usr/share/man/man1/ls.1.gz
```

# 3. head

Displays the beginning of a file.

Create a practice file:

```bash
seq 1 20 > numbers.txt
```

View first 10 lines:

```bash
head numbers.txt
```

View first 5 lines:

```bash
head -n 5 numbers.txt
```

# 4. tail

Displays the end of a file.

View last 10 lines:

```bash
tail numbers.txt
```

View last 5 lines:

```bash
tail -n 5 numbers.txt
```

### Note

If we add new lines at the end of a file:

- `head` will still show the beginning.
- `tail` will show the newly added lines.


# 5. tee

Displays output on the screen and saves it to a file.

Create a file:

```bash
echo "Hello Linux" | tee hello.txt
```

Append to the same file:

```bash
echo "Day 5 completed" | tee -a hello.txt
```

View the file:

```bash
cat hello.txt
```

# Important Commands Practiced

```bash
find

```

---

# Key Takeaways

- Use `find` for live filesystem searches.
- Use `locate` for fast database searches.
- Use `which` to find the executable path.
- Use `whereis` for executable and documentation locations.
- Use `head` to view the beginning of files.
- Use `tail` to view the end of files, especially log files.
- Use `tee` to display output while saving it to a file.
